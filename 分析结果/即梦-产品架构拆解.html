1. 执行摘要

核心架构判断

【已确认】即梦AI以统一输入框承接文本、图像、视频、音频、主体引用和技能，并提供 Agent、图片、视频、音乐、配音、数字人、动作模仿七种创作类型。技能层同时支持官方技能、用户技能、分类检索、添加、Agent 创建、管理和发布；模型层按创作类型暴露图片、视频与音乐模型。任务结果进入会话和资产库，并可继续转视频、进入画布、执行后处理或交给剪映。

证据边界

【未知】后台真实 Agent 数量、模型 API 标识、数据库、任务队列和审核实现不可见。页面已确认一次生图记录消耗 12 积分、历史视频存在超时失败及重试入口，但冻结、退款、幂等和资产版本规则仍不可见。本次没有点击生成、再生成、编辑、下载、添加技能、购买或付费按钮。

16. 关键风险

优先级风险清单

P0
请求、计费与可见结果数量不一致

请求4张并按3积分/张消耗12积分，但当前只可见2张；成功、失败或隐藏结果口径不透明。

P1
失败恢复与积分关系不透明

视频超时可反馈和重试，但是否自动重试、退款或再次扣费未说明。

P1
Skill权限与版本风险

官方和用户Skill可添加、创建和发布，但运行权限、工具白名单与版本追踪不可见。

P1
多模态参考与隐私边界

视频可接收图、音、视频与声音参考，真人脸限制仅在部分模型描述中出现。

P1
资产版本边界不透明

再生成、超清、补帧、改图和画布操作可能产生新任务、新资产或覆盖版本。

P2
Agent能力边界不可见

Agent模式与Skill均可调用创作能力，但内部专业Agent、交接与自动路由未知。
